# Gitiyverse LLC

Экосистема Gitiyverse LLC, созданная Курлыкой.

## Подсервисы

- **Gitiy** — ядро экосистемы
- **Motod** — хаб для ядра, информация и контент
- **Boid** — каталог плагинов и услуг
- **Tundunse** — каталог файлов для скачивания
- **Sdot (Secure Dot)** — бесплатное прокси
- **Sadver (Secure Advertisement)** — защищённые рекламные сообщения за плату
- **Spectrum** — библиотека музыки и книг
- **BudSpace** — социальная сеть и коллаборации
- **Aerial** — игра на базе BudSpace
- **kurlikat!** — сервис звонков
- **bluCoins** — блокчейн криптовалюта
- **YusixGPT** — ИИ и нейросети
- **Gitiy Linux** — дистрибутив GNU/Linux
- **GDE** (Gitiy's Desktop Environment), **GWM** (Gitiy's Window Manager), **HDM** (High Display Manager) — графическое ПО для GNU/Linux

> GDE похож на GNOME и XMB, есть две кнопки: список приложений и список медиа, и они все в стиле XMB. Рабочий стол в стиле GNOME.

## Gitiy Linux

Основан на Debian, имеет несколько блендов:

| Бленд | Назначение |
|-------|------------|
| SciBlend | Пакет программ для исследования |
| AstronoBlend | Для астрономии |
| CodeBlend | Для программирования |
| AlgBlend | Для математики |
| PlayBlend | Для игр |
| ArtBlend | Для студии, художников |
| LiteBlend | Минимализм |
| BlendPro | Проприетарный пакет программ |
| Default | Без бленда |

GDE и HDM имеют интерфейс, сочетающий элементы XMB и GNOME + Yaru.

## Дополнительные идеи

- Игровая валюта и система «работ» для её получения
- Простая база данных типа JSON с шифрованием: логин, пароль, специальный код для защиты аккаунта

Тема сайта: оранжевый, синий и зелёный. Округлённый минимализм с выносками. Тема не напрягает глаза и мозги.
