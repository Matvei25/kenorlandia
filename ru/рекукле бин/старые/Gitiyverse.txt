Сайт на Python для экосистемы Gitiyverse, которая содержит подсервисы:

Gitiy LLC - ядро.
MorMat&6d - хаб для ядра где можно найти информацию и контент.
Boid - каталог плагинов и услуг.
Tundunse - каталог файлов для скачивания.
Spectrum - библиотека музыки и книг.
BudSpace - соцсеть и коллаб.
Aerial - BudSpace но это игра.
kurlyka! - звонки.
bluCoins - блокчейн криптовалюты.
YusixGPT - ИИ и нейросети.
Gitiy Linux - дистрибутив GNU/Linux.
GDE (Gitiy's Desktop Environment), GWM (Gitiy's Window Manager) и HDM (High Display Manager) - графическое ПО для GNU/Linux.
...и так далее.

GDE и HDM имеют интерфейс который наполовину XMB наполовину GNOME + Yaru.

Gitiy Linux основан на Debian и имеет несколько блендов:
SciBlend - пак программ для исследования.
AstronoBlend - для астрономии.
CodeBlend - для программирования.
AlgBlend - для математики.
PlayBlend - для игр.
ArtBlend - для студии, художников.
LiteBlend - минимализм.
BlendPro - проприетарный пак программ.
Default - без бленда.

Также стоит добавить игровую валюту, "работы" чтобы эту валюту получать. Простую базу данных типа JSON но с шифрованием: логин, пароль, специальный код чтобы аккаунт просто так не взломать.

Тема сайта: оранжевый, синий и зелёный. Округлённый минимализм с выносками и тема, чтобы не напрягать глаза и мозги.
