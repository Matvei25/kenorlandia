# Gitiyverse LLC

The Gitiyverse LLC ecosystem, created by Kurlyka.

## Sub-services

- **Gitiy** — the core of the ecosystem
- **Motod** — a hub for the core, information and content
- **Boid** — a catalog of plugins and services
- **Tundunse** — a catalog of files for download
- **Sdot (Secure Dot)** — a free proxy
- **Sadver (Secure Advertisement)** — paid protected ad messages
- **Spectrum** — a library of music and books
- **BudSpace** — a social network and collaborations
- **Aerial** — a game built on BudSpace
- **kurlikat!** — a calling service
- **bluCoins** — a blockchain cryptocurrency
- **YusixGPT** — AI and neural networks
- **Gitiy Linux** — a GNU/Linux distribution
- **GDE** (Gitiy's Desktop Environment), **GWM** (Gitiy's Window Manager), **HDM** (High Display Manager) — graphics software for GNU/Linux

> GDE is similar to GNOME and XMB, it has two buttons: an app list and a media list, and they're all in the XMB style. The desktop is in the GNOME style.

## Gitiy Linux

Based on Debian, it has several blends:

| Blend | Purpose |
|-------|---------|
| SciBlend | A software suite for research |
| AstronoBlend | For astronomy |
| CodeBlend | For programming |
| AlgBlend | For mathematics |
| PlayBlend | For games |
| ArtBlend | For a studio, artists |
| LiteBlend | Minimalism |
| BlendPro | A proprietary software suite |
| Default | No blend |

GDE and HDM have an interface that combines elements of XMB and GNOME + Yaru.

## Additional ideas

- Game currency and a system of "jobs" to earn it
- A simple JSON-type database with encryption: login, password, a special code to protect the account

## Design

Site theme: orange, blue and green. Rounded minimalism with callouts. The theme doesn't strain your eyes or your brain.
