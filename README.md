# 🌍 Kenorlandia / Кенорландия

Archive of the **Kenorlandia** lore universe — microstates, weird creatures,
tech experiments and political simulations.

## 📁 Structure / Структура

- **`ru/`** — оригинал лора на русском (source of truth, авторы — Курлыка). Русские имена файлов.
- **`en/`** — English dub / перевод `ru/` (та же структура, но английские имена папок и файлов).
- `ar/`, `zh/` — optional dubs (may be added later).
- **`геральдика/`** — flags & coats of arms (PNG) + generation prompts.
