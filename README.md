# 🌍 Kenorlandia / Кенорландия

Archive of the **Kenorlandia** lore universe — microstates, weird creatures,
tech experiments and political simulations.

## 📁 Structure / Структура

- **`ru/`** — оригинал лора на русском (source of truth, authored by Курлыка).
- **`en/`** — English dub / translation of `ru/` (mirrors the same tree).
- `ar/`, `zh/` — optional dubs (may be added later).
- **`геральдика/`** — flags & coats of arms (PNG) + generation prompts.

Внутри `ru/` и `en/` одинаковая структура:
- `Кенорландия/` — ядро лора (страны, персонажи, существа, языки, тренды, Йотагос, Альянс, прочее).
- `промпты/` — инструкции и сценарии для ИИ-генераций.
- `numberblocks/` — раздел по Нумберблокам.
- `рекукле бин/` — цифровое кладбище (старые версии и удалённые идеи).
